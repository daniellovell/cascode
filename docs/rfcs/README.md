# RFC Index

This directory holds design proposals and historical design records.

Status meanings:

- `Draft`: still open and not yet implemented.
- `Implemented`: the proposal landed and remains useful as background context.
- `Superseded`: a later design replaced this proposal.
- `Historical`: kept for context only; the live source of truth is elsewhere.

Current source of truth for shipped behavior:

- Language rules: [spec/language](../../spec/language)
- Architecture docs: [docs/architecture](../architecture/README.md)

When an RFC is no longer the current design, add a short editor's note near the top so readers do
not mistake it for live documentation.
