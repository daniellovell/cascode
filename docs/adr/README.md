# Architecture Decision Records

This directory is the home for short, immutable records of architectural decisions after they have
been made and merged.

Use an ADR when a change locks in a lasting boundary, dependency, schema, or workflow decision that
future contributors will need to understand.

Until this directory has its first ADR, treat [docs/architecture](../architecture/README.md) as the
source of truth for the current system shape and [docs/rfcs](../rfcs/README.md) as the source of
truth for proposals and historical design work.
